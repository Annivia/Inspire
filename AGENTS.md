## Data collection
### Available Data Types

The system provides complete multi-modal trajectory datasets stored in HDF5 format:

1. ✅ **Hidden states**: From every layer of the VLA model during action prediction for each timestep
2. ✅ **Action outputs**: 7-dimensional robot control vectors generated by the VLA for each timestep  
3. ✅ **Vision encoder outputs**: Raw patch features from the vision backbone (DINOv2/CLIP/SigLIP etc.) for each timestep
4. ✅ **VLM visual embeddings**: VLM-transformed visual embeddings (processed patch features) for each timestep
5. ✅ **Images**: Can be reconstructed using ultra-efficient minimal clues (3 integers per episode) via LIBERO
6. ✅ **Simulator states**: Object positions, robot joint states, end-effector poses, and complete physics metadata (reconstructable)


### Data Storage

**Structure Solution**: Multi-file format organized by generation steps for efficient layer-wise loading:
```
/optimized_trajectory_data/
├── actions.h5                    # [N_samples, 7] - The 7 generated action tokens
├── hidden_states/
│   ├── generation_step_0.h5     # Contains datasets: layer_00, layer_01, ..., layer_24
│   ├── generation_step_1.h5     # Each layer dataset: [N_samples, hidden_dim]
│   ├── generation_step_2.h5     # Layer activations when generating tokens 0-6
│   ├── generation_step_3.h5     # Separate file per generation step for memory efficiency
│   ├── generation_step_4.h5
│   ├── generation_step_5.h5
│   └── generation_step_6.h5
├── vision_features.h5           # [N_samples, patches, vision_dim] - Vision encoder outputs
├── vlm_embeddings.h5            # [N_samples, vlm_embed_dim] - VLM-transformed visual embeddings
├── episode_index.h5             # DataFrame with episode metadata + sample indexing
└── dataset_summary.json         # Dataset metadata and statistics
```

**Detailed Data Specification (CORRECTED):**

**Actions (Generated Tokens):**
- **What**: The 7 action tokens generated by the VLA model for robot control, in chunks if action chunking is happening
- **When**: Output of VLA model's generation process per timestep
- **Shape per timestep**: `[7]` - always consistent
- **Storage**: `actions.h5` with shape `[N_samples, 7]`
- **Content**: Tokenized robot actions (joint commands, gripper, etc.)

**Hidden States (Layer Activations During Generation):**
- **What**: Transformer layer activations captured during each of the 7 token generation steps
- **When**: During VLA model's `generate()` process, after each layer processes the current generation step
- **Shape per generation step file**: Contains 25 layer datasets (layer_00 through layer_24)
- **Storage**: Separate files per generation step:
  - `generation_step_0.h5`: Contains datasets `layer_00` through `layer_24`, each with shape `[N_samples, hidden_dim]`
  - `generation_step_1.h5`: Same structure for 2nd action token generation
  - ... up to `generation_step_6.h5` for 7th action token
- **Data access**: Load specific layer from specific generation step: `file['layer_05']` gives `[N_samples, hidden_dim]`
- **Key requirement**: MUST be consistent hidden_dim across all layers and generation steps

**Vision Features (Encoder Outputs):**
- **What**: Raw patch features from vision encoder backbone (DINOv2/CLIP/SigLIP)
- **When**: Extracted during visual processing, before VLA generation
- **Shape per timestep**: `[num_patches, vision_dim]` (e.g., `[256, 2176]`)
- **Storage**: `vision_features.h5` with shape `[N_samples, num_patches, vision_dim]`

**VLM Visual Embeddings:**
- **What**: VLM-transformed visual embeddings (processed patch features after VLM vision processing)
- **When**: Extracted after VLM processes raw patch features, before action generation
- **Shape per timestep**: `[vlm_embed_dim]` (e.g., `[4096]` - single embedding vector per timestep)
- **Storage**: `vlm_embeddings.h5` with shape `[N_samples, vlm_embed_dim]`

**Episode Metadata (Reconstruction Clues):**
- **What**: Minimal information to reconstruct images and simulator states using LIBERO
- **Contents**: `img_task_id`, `img_episode_id`, `img_env_seed`, `num_timesteps`, `task_description`, `success`
- **Storage**: `episode_index.h5` as Pandas DataFrame with episode indexing for efficient filtering

**Parallel Processing Structure:**
