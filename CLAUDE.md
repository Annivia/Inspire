## Overview

This is the **InSpire** repository - an implementation of Vision-Language-Action models with intrinsic spatial reasoning for robotics. The project implements VLA models based on OpenVLA architecture with a novel InSpire approach that improves spatial reasoning by appending spatial reasoning questions ("In which direction is the [object] relative to the robot") to language instructions.

### Current Development Goal

The primary objective is to **train linear probes on VLA trajectory data** to analyze the learned representations. This requires modifying the evaluation pipeline to collect and store:

1. **Hidden states**: From every layer of the VLA model during action prediction for each timestep
2. **Vision encoder outputs**: Latent representations from the vision encoder for each timestep  
3. **Action outputs**: Low-level control actions generated by the VLA for each timestep
4. **Simulator states**: Object positions, contact states, and other simulator metadata for future annotation
5. **Image reconstruction traces**: Efficient references to regenerate images from simulator (stored separately due to size)

The data will be stored in HDF5 format with hierarchical structure: `/task_{id}/episode_{id}/timesteps/` containing arrays for actions, hidden states (per layer), and annotations for linear probe training.

## Key Components

### Core Architecture
- **prismatic/**: Core VLA model implementation based on OpenVLA
  - `conf/vla.py`: VLA model configurations for different datasets and training setups
  - `models/`: VLM model architectures (vision-language-action models)
  - `vla/`: VLA-specific modules and action tokenizers
- **LIBERO/**: Robotics simulation environment and benchmarking suite
- **vq_bet_official/**: VQ-BET (Vector Quantized Behavior Transformer) implementation

### Training and Evaluation
- **vla_scripts/**: Main training and evaluation scripts
  - `train.py`: Standard VLA training 
  - `train_vqa.py`: InSpire training with spatial reasoning VQA
  - `parallel_libero_evaluator.py`: Multi-GPU evaluation on LIBERO tasks
- **scripts/**: Data preprocessing and utility scripts
  - `parallel_libero_dataset_regenerator.py`: Clean and preprocess LIBERO datasets
  - `annotate_data.py`: Add spatial annotations to real-world data

### Datasets
- **rlds_dataset_builder/**: TensorFlow dataset builders for LIBERO tasks
- LIBERO simulation tasks: libero_90, libero_10, libero_goal, libero_object, libero_spatial

## Development Commands

### Environment Setup
```bash
# Create conda environment
conda create -n inspire python=3.10
conda activate inspire

# Install dependencies
cd LIBERO && pip install -r requirements.txt && pip install -e . && cd ..
cd vq_bet_official && pip install -r requirements.txt && pip install -e . && cd ..
pip install torch==2.3.1 torchvision==0.18.1 torchaudio==2.3.1 --index-url https://download.pytorch.org/whl/cu118
pip install -r requirements-min.txt

# Optional: Flash Attention for better performance
pip install packaging ninja
pip install "flash-attn==2.5.5" --no-build-isolation
```

### HPC/SLURM Usage
This project is designed for HPC environments. Key SLURM batch scripts:
- `install.sbatch`: Environment setup with GPU allocation
- `run.sbatch`: Full evaluation pipeline with data transfer
- `test.sbatch`: Quick testing script

### Training Commands
```bash
# Baseline MiniVLA training
bash vla_scripts/train/train_baseline_libero90.sh

# InSpire training with spatial reasoning
bash vla_scripts/train/train_inspire_libero90.sh
```

### Evaluation Commands
```bash
# Download pretrained weights
bash scripts/download_pretrained_weights.sh

# Evaluate baseline model
bash vla_scripts/eval/eval_baseline_libero90.sh

# Evaluate InSpire model
bash vla_scripts/eval/eval_inspire_libero90.sh
```

### Environment Variables
- `PYTHONPATH`: Must include LIBERO and vq_bet_official directories
- `HF_HOME` or `HF_CACHE`: Hugging Face cache directory (for model weights)
- `PRISMATIC_DATA_ROOT`: Root directory for dataset storage
- `.hf_token`: Hugging Face authentication token file

## Key Model Configurations

VLA model configurations are defined in `prismatic/conf/vla.py`:
- `prism-qwen25-dinosiglip-224px+0_5b+mx-libero-90`: Main baseline configuration
- Different dataset variants: libero_90, libero_10, libero_goal, libero_object, libero_spatial
- Multi-GPU training support with configurable batch sizes and world sizes

## Testing
Use `test.py` and `test.sbatch` for development testing. The main evaluation uses the LIBERO benchmark with 10 trials per task across different task suites.

## Data Processing Pipeline
1. Download raw LIBERO datasets
2. Run `parallel_libero_dataset_regenerator.py` to clean datasets (remove no-ops and failures)
3. Build RLDS datasets using `rlds_dataset_builder/`
4. For real-world data: use `annotate_data.py` to add spatial reasoning annotations
